# Getting help

1. **Run the doctor.** `devsync doctor` checks the whole setup and explains
   what's wrong.
2. **Read the docs.** The [troubleshooting guide](docs/src/troubleshooting.md)
   and the [FAQ](docs/src/faq.md) cover the most common problems (PATH, ssh
   keys, missing agents, environment differences).
3. **Search existing issues.** Someone may have hit the same problem.
4. **Ask a question.** Use GitHub Discussions (Q&A) if enabled for the
   repository, or open an issue.
5. **Report a bug.** Use the bug report form, including `devsync doctor`
   output and the failing command with `-v`.

Security issues: see [SECURITY.md](SECURITY.md).
